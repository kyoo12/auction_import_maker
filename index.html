about download guide

auction automator

A simple python tool to convert raw auction excel dumps into standard lot import templates automatically.

Download Package (.zip)

how to use ↓

  1. Download and extract the zip file to a folder.
  2. Place your raw auction excel file in the same folder.
  3. Ensure your excel file is named exactly Wollsdorf_Leder .xlsx (or modify the script configuration).
  4. Double-click run.bat. It will automatically install dependencies and run the script.
  5. Your formatted template will be generated as lot_import_Wollsdorf_Leder.xlsx!
